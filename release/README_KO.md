# Poison Pink 한국어화 보완 개발판 v0.4.0-dev

아직 완전 한글화가 아닌 테스트 개발판입니다.

## 반영 내용

- 사용자 제작 상점·마신도감 이미지 4장 반영: dic_pt04, sys007, sys019, dic_pt02
- 기존 배포판보다 전투 음성 자막 32종 추가: 총442종/511뱅크 슬롯
- 비언어116종 제외, 불확실한34종 보류
- 기존 대사·UI·지도·영상 자막·대화 표시 수정 유지
- PCSX2 외부 패치 없이 실행

## 적용 방법

일본판 원본 ISO(SHA-256 `081e5c921fc2b0f517f007dfe053935578174a6880949de961e273426b216103`)에 `Poison_Pink_Korean_update_v4.xdelta`를 xdelta3로 적용하세요.
macOS/Linux는 apply_patch_ko.sh, Windows는 apply_patch_ko.ps1을 사용할 수 있습니다.
원본·패치·출력의 해시를 확인하며 기존 출력 파일을 덮어쓰지 않습니다.
출력 SHA-256: `b6601a8b7a6a5c6de956a9ccaa33804a304429e29cfa94bbe9e7d7f59a017445`
패치 SHA-256: `dfb1389c87fffcfd4350253cf30bf2d3e1f6c8121aab6be3c689bcfc52782267`
패치 크기: 316,619,009바이트. 출력 ISO: 4,245,454,848바이트.

## 검증 범위

전체 ISO 변경 범위와 기존 게임 코드·heap·독립 실행 보정 보존 확인.
최신442종 번역 카탈로그의 MIPS 실행 시험4개/592종 매칭 통과.
이미지4장 원본 팔레트·헤더·글자 영역 밖 인덱스 및 적용 멤버 검증 통과.
전사는 full Whisper large-v3와 외부 서비스 결과를 텍스트로 대조했습니다.
GPT 직접 원음 청취나 사람의 전체 음성 청취 검수는 수행하지 않았습니다.
v4 자체 게임 실행과 전체 게임·실기 검증은 아직 하지 않았습니다.

새 ISO로 부팅하고 게임 내 메모리카드 저장을 불러오세요.

GitHub에는 원본/수정 ISO·음성·PSD·저장 데이터 대신 원본 ISO용 차분 패치를 배포합니다.
