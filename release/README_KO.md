# Poison Pink 전투 음성 자막 테스트 개발판 v0.3.0-dev

> 아직 완전 한글화가 아닌 테스트 개발판입니다. 모든 전투 음성을 사람이 직접 청취한 검수본이나 전체 게임 실행 검증 완료판이 아닙니다.

## 적용 방법

1. 본인이 소유한 일본판 원본 ISO를 준비합니다.
2. 원본 SHA-256이 `081e5c921fc2b0f517f007dfe053935578174a6880949de961e273426b216103`인지 확인합니다.
3. xdelta3를 설치합니다.
4. `Poison_Pink_Korean_battle_subtitles_v3.xdelta`를 적용합니다.
5. 출력 SHA-256이 `8ba7111a988b095902e727f089bdf5ac12778c59cfeb127e193402ce17a888b9`인지 확인합니다.
6. 생성된 ISO를 PCSX2에서 외부 패치 없이 새로 부팅합니다.

macOS/Linux는 `apply_patch_ko.sh`, Windows는 `apply_patch_ko.ps1`을 사용하면 원본·패치·출력 해시를 자동 검증합니다.

## 이번 개발판 반영 내용

- 기존 한국어 대사·UI·지도·영상 자막과 독립 실행 대화 레이아웃 수정 유지
- 중복 제거 전투 음성 592종 중 410종, 456개 뱅크 슬롯에 한국어 자막 추가
- 무음·신음·비언어 기합 102종 제외
- 인식 결과가 불확실한 80종은 미적용
- 음성 재생에 맞춰 2~4초 표시하고 다음 번역 발화가 기존 문구 갱신
- 행동 순서 아이콘을 피하도록 자막을 Y=330에 배치
- `.pnach`, `.iso.pcsx2`, 호환 ZIP 없이 실행

## 검토 방식과 실행 검증

- 일본어 음성 인식 결과와 한국어 문구를 대조했으며 사람이 모든 원음을 직접 청취한 검수는 아닙니다.
- 생성 MIPS 명령 실행 시험 4개가 592개 음성 매칭, descriptor 범위, 타이머/리셋, ELF 세그먼트/heap 배치를 확인했습니다.
- 최종 v3를 PCSX2 2.6.3 Software 4:3, 외부 패치 OFF로 새 부팅해 RAM의 코드·문구·좌표를 확인했습니다.
- 동일 코드 이전 v1에서 메모리카드 사본 불러오기, 전투 준비·맵·마법 대상 UI를 확인했습니다.
- 복사 상태에서 게임 음성 함수를 한 번 호출해 `가거라!`, `조디아여!` 자막 표시를 확인했습니다. 시험용 재생 helper는 ISO에서 제외했습니다.
- 자연스럽게 조작한 공격의 최종 자막, 전체 게임, Metal 전투, 실제 PlayStation 2는 검증하지 않았습니다.

## 주의

- 새 ISO로 완전히 부팅한 뒤 게임 내 메모리카드 저장을 사용하세요.
- 이전 강제 상태저장은 옛 실행 코드와 좌표를 복원할 수 있으므로 사용하지 마세요.
- 원본/수정 ISO, BIOS, 음성 원본, RAM, 상태저장, 메모리카드는 배포물에 포함되지 않습니다.
- 출력 ISO는 약 4.25GB이며 xdelta 자체는 316,602,347바이트(약 302MiB)입니다.
- PCSX2 2.6.3의 명시한 범위 이외 환경과 전체 플레이는 보장하지 않습니다.
