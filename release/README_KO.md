# Poison Pink 한국어화 독립 실행 개발판 v0.2.0-dev

> 아직 완전 한글화가 아닌 개발·검수 중인 버전이며, 미번역 이미지와 추가 검수가 필요한 내용이 남아 있습니다. 전체 게임 실행 검증 완료판이 아닙니다.

## 적용 방법

1. 본인이 소유한 일본판 원본 ISO를 준비합니다.
2. 원본 SHA-256이 `081e5c921fc2b0f517f007dfe053935578174a6880949de961e273426b216103`인지 확인합니다.
3. xdelta3를 설치합니다.
4. `Poison_Pink_Korean_standalone_v1.xdelta`를 적용합니다.
5. 출력 SHA-256이 `f7276bfe1da4b9599d5242daa74ee094ac87e3044173e3c943b6320890fed072`인지 확인합니다.
6. 생성된 ISO를 PCSX2에서 외부 패치·치트·와이드스크린 패치 없이 새로 부팅합니다.

macOS/Linux는 `apply_patch_ko.sh`, Windows는 `apply_patch_ko.ps1`을 이용하면 원본·패치·출력 해시를 자동 검증합니다.

## 이번 개발판 반영 내용

- 최신 지역명 이미지 11종
- 최신 지도 이미지
- 상점 메시지와 컨트롤러 안내문
- 클래스 체인지 문구 수정
- 누적 대사·UI·영상 자막 한국어화 작업
- 초상화 대화 레이아웃 수정 4개 값을 ISO에 통합
- `.pnach`, `.iso.pcsx2`, 호환 ZIP 없이 실행하는 최신판

## 실제 실행 검증 결과

- 출력 ISO SHA-256: `f7276bfe1da4b9599d5242daa74ee094ac87e3044173e3c943b6320890fed072`
- PCSX2 2.6.3 Software 4:3 무패치 새 게임에서 첫 초상화 대사, 여러 인물·두 줄 대사, 전투 준비, 첫 본편 전투 대사와 유닛 이동을 확인했습니다.
- 기본 Metal 4:3 무패치 새 게임에서 첫 초상화 대사와 이후 진행을 확인했습니다.
- Software 16:9 무패치에서 기존 레벨 23 메모리카드 복사본의 저장 불러오기와 해당 전투 로딩을 확인했습니다.
- 이전 DMAP flow v1과 비교해 6바이트만 변경됐으며 나머지 전체 바이트, 기존 번역·이미지·영상, 4:3 시야각과 폰트 폭은 보존됐습니다.
- 전체 플레이, 다른 PCSX2 버전, 실제 PlayStation 2는 검증하지 않았습니다.

## 주의

- 세이브를 백업하세요.
- 원본/수정 ISO는 배포물에 포함되지 않습니다.
- 출력 ISO는 완전한 디스크 이미지이므로 약 4.25GB입니다. xdelta 파일 자체는 약 297MiB입니다.
- 일부 이미지, 문맥 의존 번역, 영상 가사와 런타임 분기는 추가 검수가 필요합니다.
- 과거 강제 상태저장은 사용하지 말고 새 ISO를 새로 부팅한 뒤 게임 내 메모리카드 저장을 사용하세요.
- 이 배포에는 PCSX2용 `.pnach`, `.iso.pcsx2`, 호환 ZIP이 포함되지 않습니다.
