# 검은 글자 효과 누락 수정

## 원인

사용자가 원본 패배조건 ‘주인공의 전투불능’은 검은 효과가 나오지만 한글화한 적 격파 문구는 보이지 않는다고 보고했다.

기존 공통 PSD 생성기는 `bt_tx08`을 기본 PSD의 **문자 레이어 알파만**으로 만들었다. 흰색 외곽선은 레이어 효과라 이 알파에 없었다. 원본 `bt_tx05`와 `bt_tx08`은 전체 실루엣(테두리 포함)이 거의 일치한다. 원본 두 이미지의 알파 128 이상 영역 교집합/합집합은 0.99645다. 기본 글자와 검은 효과를 단순히 같은 위치에 맞추는 것만으로는 빠진 테두리가 복구되지 않는다.

기존 변환 방식의 누락이며 사용자가 다시 식자해야 하는 문제가 아니다.

## 수정

`tools/battle_lettering_layout.py`에서 검은 효과의 알파를 기본 글자의 **최종 합성 알파 전체**로 바꿨다. 어두운 색, 팔레트, 메시, 연출 시각과 기존 공간 보정은 유지한다. 공통 PSD에서 기본 이미지와 검은 이미지의 알파가 정확히 같아야 하는 회귀 검사를 추가했다. 향후 테두리 변경도 검은 실루엣에 포함해야 한다.

공통 좌표로 역변환해 확인한 흰 테두리 영역의 검은 효과 커버율:

- 수정 전: 4.43%
- 수정 후: 94.50%

이는 축소·팔레트 변환 후 알파 128 기준의 정적 면적 지표이며, 실제 화면의 불투명도 비율을 뜻하지 않는다.

## 적용 파일

- 새 작업본: `outputs/battle_lettering_aligned_v4/`, 같은 이름의 ZIP
- 새 ISO: `build/battle_shadow_v1/Poison Pink (Japan) - Korean battle shadow fix v1.iso`
- ISO SHA-256: `7cc52fc3027ed9ec51aa8ffd60ec29fc0864995f1613032bab72d6c67c8ee1b7`

이전 정렬 보정 ISO 위에서 **bt_tx08 인덱스 4,469바이트만** 바꿨다. bt_tx05·06·07, 제목, 패배조건 원본, 다른 이미지·대사·ELF는 동일하다. 전체 ISO 비교와 인벤토리 일치, TIM2 헤더·팔레트·직렬화 검사를 통과했다. CRC는 7502FF83으로 기존 PCSX2 보정과 같다.

작업본 v3 및 사용자 원래 PSD는 수정하지 않았다. 이후 편집용 기본 작업본은 v4다. 공통 빌더에 기준 ISO·해시·작업본·출력 경로 옵션을 추가해 새 개정을 기존 ISO 덮어쓰기 없이 생성하도록 했다.

## 검증

레이아웃 6개와 기존 텍스처·알파 검사 6개, 총 12개 테스트가 통과했다. 원본 기본/검은 효과의 전체 실루엣 일치와 새 PSD의 테두리 포함 여부를 별도로 검사한다.

사용자 세이브와 메모리카드의 복제본을 사용하는 별도 PCSX2 2.6.3 Software에서 1/4 속도로 전투 소개를 촬영했다. 새 한글 본문이 흰 테두리 → 주황색/붉은 효과 → 검은 글자 → 사라짐으로 진행하는 구간을 확인했다. 같은 실행에서 원본 패배조건의 검은 단계도 확인했다.

- 수정본 어두운 단계: `build/battle_shadow_v1/snaps/Poison Pink_SLPS-25854_20260919231923.png`, `...231924.png`
- 수정본 사라짐: `...231925.png`
- 원본 패배조건 검은 단계: `...232043.png`
- 실행 로그: `build/battle_shadow_v1/runtime.log`

다른 문구나 전체 전투 UI의 모든 효과를 검증한 것은 아니다. 이번 변경은 한글화한 적 격파 본문의 검은 효과에 한정한다.

같은 조건 비교 실행에서도 차이를 확인했다. 이전 v3의 `...232259.png`·`...232300.png`는 밝은 테두리를 남긴 채 사라지고, 수정본 `...231923.png`·`...231924.png`는 테두리가 어두워진 상태를 거친다. 서로 프레임 번호까지 동기화한 비교라는 뜻은 아니며 각 실행의 사라지기 직전 구간이다. 비교 이미지는 `build/battle_shadow_v1/shadow_before_after.png`, 결과 보고서는 `reports/battle_shadow_fix_v1.json`이다. 테스트 앱을 종료했고 속도와 프로젝트 INI를 실행 전 상태로 복원했다. 사용자 상태저장 1번과 원래 PSD들의 해시도 그대로다.
