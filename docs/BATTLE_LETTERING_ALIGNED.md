# 전투 본문 식자: 공통 좌표 PSD와 게임 배치 역산

## 결과

최신 ISO: `build/battle_registration_v2/Poison Pink (Japan) - Korean battle lettering aligned v3.iso`

SHA-256: `3f3e8c39ed023aee41e9ddb1205c3d76ccd9c92c4dfe51cdfd5a738ff852f7f1`

공통 작업본: `outputs/battle_lettering_aligned_v3/` 및 동명 ZIP. `모든적격파/`의 PSD 4장은 모두 1024×512이며 동일한 글자 중심·자간·줄 위치를 쓴다. 색과 외곽 효과만 다르다. 기본 문구는 사용자 작성 ‘남김없이 격파하라’다. 원래 PSD는 보존했다.

## 원인 확인

원본 TM2 4개를 다시 해독한 RGBA가 추출 PNG와 전 픽셀 일치했다. 추출 시 자르거나 재배치한 문제는 아니다. 원본 게임이 효과마다 다른 배치를 저장하고, 그리면서 되돌린다.

`bt_sjkn_std.upl`의 본문 첫 네 평면 정점과 UV 좌표를 대조했다. 빨간 효과의 평면 너비는 약 336.474, 기본 글자는 256으로 약 1.314배 차이다. 빨강·주황의 둘째 줄은 기본 글자와 별도 위치에서 시작한다. 검은 실루엣은 첫째 줄이 기본 글자와 같은 평면 배치이고 둘째 줄은 작은 위치·배율 차이가 있다. 메시의 추가 정점과 애니메이션에는 입체 변형도 있어 이 수치를 전체 시간축의 화면 배율이라고 단정하지 않는다.

과거 적용기는 기본 글자와 검은 실루엣의 PNG 좌표만 맞추고, 빨강·주황은 사용자가 각각 편집한 자간과 크기를 그대로 썼다. 네 장을 실제 게임 배치로 환산해 겹쳐 보는 검사가 없었다. 새 방식은 기본 글자의 저장된 문자 레이어 모양을 공통 기준으로 사용하고 게임 배치를 역산한다.

## 구현

- `tools/battle_lettering_layout.py`: 원본 UPL 해시 고정, 정점·UV 앵커 일치 확인, 공통 PSD 생성, 효과별 역변환.
- `tools/build_battle_registration.py`: 공통 PSD의 보이는 작업 레이어를 합성하고 256×128로 변환, 원래 팔레트와 헤더를 유지해 TIM2/ISO에 반영.
- 참고 글자·확인 배경 레이어는 내보내기에서 제외한다.
- 줄별로 분리해 변환하므로 이웃 줄의 픽셀이 섞이지 않는다. 게임 텍스처 밖으로 잘릴 배치는 중단한다.
- 빨간 효과는 사용자 PSD에 있던 외곽 획을 유지했다. 압축된 작업본의 8px 획에 대응하도록 공통 작업본에서는 약 10.5px로 표시한다. 단순히 기본 글자와 같은 마스크만 쓰면 뒤에 가려지는 문제가 있어 수정했다.
- 검은 실루엣은 밝기를 임의로 높이지 않고 원래 색·팔레트를 유지했다. 어두운 단계의 독립적인 가시성 검증을 완료한 것은 아니다.

## 검증

- 추출 RGBA 동일성, 빨간 메시 배율, PSD 보조 레이어 제외, 양쪽 줄의 패킹 후 정렬, 잘림 거부를 검사했다.
- 레이아웃 5개 + 텍스처 코덱·타이틀 알파 관련 6개, 총 11개 검사 통과.
- 기본 `bt_tx05`는 적용 전과 바이트 동일. `bt_tx06~08`의 픽셀 인덱스 8,442바이트만 바뀌었다. 전체 ISO 비교에서 나머지 바이트가 모두 동일함을 확인했다.
- 사용자 세이브와 메모리카드의 복제본을 쓰는 별도 PCSX2 2.6.3 Software에서 첫 전투 소개를 재생했다. 불꽃으로 글자가 나타나는 과정, 본문 빨간 테두리의 정렬, 주황 윤곽 전환을 캡처했다. ISO 실행 경로는 `final-runtime.log`에 기록되어 있다.
- 세이브 복제본의 EE RAM에서 기존 `bt_tx06~08` 원시 TM2 블록이 검출되지 않음을 확인했다. 같은 상태를 새 ISO로 복원해 소개 연출부터 촬영했다. GS 캐시를 별도로 전수 분석한 것은 아니다.
- 테스트 창은 종료했고 프로젝트 INI를 실행 전으로 복원했다. 사용자 창·상태저장·메모리카드는 쓰지 않았다.

결과와 해시: `reports/battle_lettering_aligned_v3.json`. 실행 증거: `build/battle_registration_v2/snaps/Poison Pink_SLPS-25854_20260919230806.png`, `...230809.png`, `...230810.png`.

## 범위와 남은 부분

이 공통 배치와 보정은 **적 격파 본문 bt_tx05~08**에만 적용된다. 승리조건/패배조건 제목 bt_tx04는 그대로다. 다른 조건 문구, 제목, 구속/포획은 각자 조각·메시를 분석한 변환표가 필요하다. 네 개 텍스처를 네 개의 독립된 연출 단계로 취급하지 않는다. 검은 실루엣만 분리한 화면이나 전체 애니메이션의 프레임별 일치까지 검증한 것은 아니다.
