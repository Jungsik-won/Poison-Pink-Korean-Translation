# 사용자 TSV 번역 적용

## 결과

2026-09-17에 전달받은 두 TSV의 확인된 오류를 보완하여 새 ISO에 반영했다.

- ISO: `build/user_translations_v1/Poison Pink (Japan) - Korean text v1.iso`
- SHA-256: `7a9f425a5bfc883d94349888445b87684c66315b854782b7c69fa4468c63b3e8`
- 대사·화자 등 RTB 문자열 **116,616행**, 아이템·스킬·캐릭터 DB **1,388행**, 검증된 ELF 화면 문자열 **124행** 반영.
- 사용자 제작 로고·타이틀·전투 메뉴·도움말 등 **28개 자산을 직전 ISO와 바이트 단위로 동일하게 유지**했다.
- 원본 게임 폴더, 전달받은 바탕화면 TSV, 이전 이미지 통합 ISO는 변경하지 않았다.

## 보완 내용

- 잘못 추출된 게임 전용 글자 `凸` 때문에 생긴 ‘마볼록’, ‘마볼’, ‘마돌’ 및 용어 누락을 수정했다. `魔凸`의 게임 표시 의미는 ‘마신’이다. 같은 문제를 가진 장비·스킬 이름과 반복되는 마신 도감 설명도 보완했다.
- 저장 한도를 넘던 이름 7개를 의미에 맞게 줄이고 ‘주석 지팡이→석장’, ‘모순→창’ 등의 오역을 정정했다.
- 기존 검수 용어와 튜토리얼·DB 표본 번역을 우선 사용했다.
- 긴 대사 132종은 원문을 대조해 간결하게 고쳤다. 뜻이 뒤집히거나 빠진 문장도 함께 수정했다.
- 그 외 줄바꿈을 조정했다. 글자를 임의로 잘라 버리지 않으며, 원문 함수에서 관찰한 줄 폭을 참고했다. 이는 정적 추정이므로 모든 창에서 실제 표시를 보증하는 것은 아니다.
- 마지막 점검에서 `본番`과 `결ㅁ` 표기도 수정했다.
- 사용자 번역 대비 번역 칸이 달라진 행은 **2,863행**이다. 이 수에는 반복 대사·줄바꿈과 적용 보류된 ELF의 수정안도 포함된다.

## 적용에서 제외한 항목

- `root/config.txt`, `dmap/startmap.txt` 전체 번역 2행은 설정 파일이므로 적용하지 않았다.
- ELF 변경 번역 2,179행 중 124행만 반영했다. 나머지 **2,055행**은 내부용·미확인 문자열, 저장 공간을 넘는 문구, 참조 추가 확인 대상 등으로 분리했다. 이 전체가 오류라는 뜻은 아니다.
- 기존에 적용된 공통 선택지 `ELF:0x00452820`은 이번 참조 탐색에 잡히지 않아 재적용하지 않았으며, 이전 한글 표시는 그대로 유지된다.
- ELF 수정본의 `ready`는 사전검사 상태다. 실제 반영 여부는 최종 보고서 `elf` 목록이 기준이다. `deferred` 행은 새로 주입하지 않는다.
- 승리·패배 조건의 ‘적 전멸’, ‘주인공 전투불능’, 보스 격파 문구는 반영 대상에 포함된다.

## 수정본과 검증 기록

- 수정된 구조화 TSV: `localization/imports/20260917_corrected/structured_ko_corrected.tsv`
- 수정된 ELF TSV: `localization/imports/20260917_corrected/elf_ko_corrected.tsv`
- 사용자 원본 사본: `localization/imports/20260917/`
- 행별 수정 내역: `localization/imports/20260917_corrected/changes.jsonl`
- 보류 목록: `localization/imports/20260917_corrected/deferred.jsonl`
- 최종 보고서: `reports/user_translations_applied_20260917.json`

두 수정 TSV는 열·행 순서·ID·원문·위치를 보존하고 `target`과 `status`만 변경했다. 계속 작업할 때도 원문 열은 수정하지 않는다.

RTB 280개와 DB 3개를 파싱하여 문자열 외 데이터, 명령·분기 구조, 변경 대상이 아닌 기존 문자열을 보존했다. 글리프 924개를 추가하여 총 3,136개로 확장했고, 기존 2,212개 글리프와 코드 매핑은 그대로 유지했다. 사용 중인 코드와 겹치지 않는 슬롯을 사용하고 인코딩·글리프 왕복을 검사했다. SYSTEM.DAT만 ISO의 확인된 빈 공간으로 옮겼으며, DMAP·STATUS의 ISO 위치와 모든 텍스처 내용은 유지했다.

코덱·ISO·폰트 관련 테스트 27개와 전체 ISO 변경 범위 검사가 통과했다. 마지막 두 표기 수정 후에도 직전 이미지 통합 ISO와 전체 바이트를 다시 비교했다. 게임 실행 검증은 사용자 방침대로 보류했다. 전체 대사의 의미·말투를 전수 교열한 완성 번역본이라는 뜻은 아니다.

## 재현

`tools/prepare_user_translation_import.py`가 수정 및 선별 계획을 만들고 `tools/build_user_translation_import.py`가 원본 사본과 이전 이미지 통합 ISO를 기준으로 빌드한다. 기존 결과 덮어쓰기는 거부한다. TSV 저장에는 `build/user_translation_tools/write_corrected_tsv.mjs`를 사용했다. 마지막 표기 2곳은 `tools/finalize_user_translation_import.py`로 추가 반영했으며 현재 준비 도구에도 같은 수정이 포함돼 있다. 최종 입력·출력 해시와 마지막 보완 이력은 최종 보고서를 따른다.
