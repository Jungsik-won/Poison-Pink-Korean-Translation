# 공통 메뉴·도움말 한글화 파이프라인

후속 최신 빌드와 현재 재현 지점은 [스킬 분류·상태·명령 통합본](UI_REMAINING.md)을 따른다. 아래는 UI v3 단계 기록이다.

2026-09-15. **전투 명령 9종의 25개 이미지 조각과 첫 도움말의 제목·본문**을 주입했다.
전체 UI 번역의 첫 표본이며, 상단 행동 제목·분류 제목·나머지 도움말은 별도 작업이다.

## 검수에서 바로잡은 내용

원본 `開ける`를 처음에 ‘닫기’로 잘못 읽었다. 비활성 항목의 실행 검수와 ELF의 독립 문자열
`0x453488`을 대조해 **‘열기’**로 정정했다. `sys000`의 UAD 번호 2·3·33을 모두 고쳤다.
`build/ui_slice/`, `build/ui_slice_v2/`는 비교 증거이며 최종 플레이용으로 사용하지 않는다.

최종 메뉴 용어는 **이동, 공격, 스킬, 명령, 열기, 포획, 도구, 상태, 대기**다.
25개 조각은 선택 가능/불가, 보조 표시 등 같은 용어의 변형이다. 25개 모든 변형의 실행 조건을
각각 유도한 것은 아니며, 실제 표시한 용어와 기능은 실행 보고서에서 구분한다.

## 원본 구조와 도구

| 대상 | 확인한 구조 | 처리 |
| --- | --- | --- |
| `status/sys000.tm2` | 512×256, 8비트 인덱스, 팔레트 256색 | 64×24 명령 조각 25개만 교체 |
| `status/sys000.uad` | 59개 조각, big endian 좌표 | 읽기·범위 검증만 수행, 전체 파일 보존 |
| `dmap/ev/ev135.tm2` | 640×384, 8비트 인덱스 | 제목·말풍선 본문 두 사각형만 교체 |
| STATUS·DMAP의 TIM2 | 총 2,089개 | 분리/직렬화 후 원본 전체 바이트 일치 |

`tools/ui_texture_codec.py`는 이 게임에서 관찰된 버전 4·정렬 0·단일 picture·mipmap 1의
4/8비트 인덱스 형식만 허용한다. 원시 GS 알파, 중복 팔레트 색, 모든 헤더 바이트를 보존한다.
PNG용 알파 배율 변환은 미리보기에만 적용한다. PNG를 다시 읽어 무변경 왕복을 주장하지 않는다.

- 8비트: STATUS 103개, DMAP 1,816개. 4비트: STATUS 1개, DMAP 169개.
- 4비트 니블의 정확한 왕복은 검사했지만 모든 그림의 GS 표시 배열을 화면 검증한 것은 아니다.
- UAD는 `16 + 조각 수×32`까지의 좌표 구조를 읽는다. 뒷부분의 참조 의미는 아직 해석하지 않았으며 원본을 유지한다.
- `tools/ui_texture_audit.py`: 원본 HED/DAT 해시 확인 → 전체 TIM2 왕복 → 메뉴·도움말 후보 미리보기와 보고서.
- `tools/ui_catalog.py`: 화면으로 분류한 메뉴 아틀라스 10개, 도움말·관련 그림 27개의 우선순위와 제목 초안.
- `reports/ui_elf_candidates.json`: 행동 제목·공통 선택 항목의 ELF 문자열 위치 후보. 참조/용량 분석 전이므로 아직 주입하지 않는다.

## 번역·주입 순서

1. 원본 그림과 실제 화면의 의미를 함께 확인한다. 텍스트가 비슷해 보여도 기능을 대조한다.
2. 원본 파일 해시, UAD 번호·사각형, 원본 픽셀 인덱스 해시, 번역문·검수자를 묶는다.
3. 이미지를 제작하고 한글 철자를 검수한다. 이번 시안은 built-in `image_gen`을 사용했다.
   [입력 이미지·생성 프롬프트](../localization/ui_image_prompts.json)를 남겼다.
4. 생성 이미지 전체를 교체하지 않는다. `ui_slice.py`가 검수된 사각형만 고정 크기로 샘플링하고
   **원본 팔레트의 불투명 색**에 대응시킨다. 원본 CLUT를 새로 만들거나 재정렬하지 않는다.
5. 겹친 사각형, 범위 밖 좌표, 소스/이미지 해시 불일치, 미검수 항목, 크기·알파 조건 불일치를 거부한다.
   기존 사각형 밖의 모든 픽셀, TIM2 헤더·CLUT가 보존됐는지 확인한다.
6. 별도 ISO를 만들고 바탕 ISO와 전체 바이트를 독립 대조한다. 원본이나 완료된 ISO를 덮어쓰지 않는다.
7. 새 부팅, 선택 강조·비활성 표시, 하위 화면 진입·취소·다음 턴, 저장 데이터 로드를 확인한다.

이미지 생성은 비결정적이다. 재현 빌드는 **보존한 PNG와 그 해시**를 입력으로 사용한다.
생성 이미지의 크기는 메뉴 1774×887, 도움말 1619×971이었으며 원본 비율에서 출력 1픽셀 이내의
반올림만 허용한다. 본번역 전에 작은 글자의 두께와 사각형 배경 경계도 추가로 다듬을 수 있다.

## 실행 검증과 한계

- UI v2: 첫 한글 도움말 표시·닫기·다음 원본 도움말 전환, 기존 한글 대사 표시 확인.
- UI v2: 9개 메뉴 표시, 이동·공격·스킬·명령·도구·상태 화면 진입과 취소, 대기 후 다음 턴 진행 확인.
  이 시점의 ‘닫기’ 오역은 실패로 판정해 최종 v3에서 ‘열기’로 수정했다.
- 최종 v3의 도움말 payload는 UI v2에서 화면 검수한 파일과 SHA-256이 같다.
- 최종 v3: 상태 파일 없이 새 부팅해 No.02를 로드하고 본편 첫 전투에 진입했다. ‘열기’ 수정 표시와
  기존 한글 스킬의 동시 표시를 확인했다. 같은 ISO에서 상태 저장·복원도 1회 통과했다.
- 첫 출격에는 교체할 여분 장비가 없었다. 목록 열기는 확인했지만 실제 장비 교환은 미검증이다.
- ‘열기’와 ‘포획’의 비활성 표시는 확인 범위다. 유효 상자/구속 대상에서 실행하는 조건은 별도 검증해야 한다.
- 상단 `移動`·`待機`, 스킬 분류 제목, 인물의 정식 이름, 도움말 속 원본 화면의 이름·수치는 이번 이미지 교체 범위 밖이다.
- 입력·캡처가 한 차례 전달되지 않았다. 스레드 샘플에서 앱 이벤트 루프와 에뮬레이션은 실행 중이었다.
  `open -a build/runtime/PCSX2-v2.6.3.app`으로 창을 활성화한 뒤 캡처와 입력이 복구됐다. 원인은 단정하지 않는다.
- 초기 카드 검증에는 사본만 사용했다. 기존 진행 카드 두 개의 해시는 유지됐고 기존 설정으로 복원했다.
- 전체 P4와 배포 준비는 미완료다.

   ELF 15곳의 참조·고정 용량 검증과 표본 실행은 [후속 단계](UI_TITLES.md)에서 완료했다. `sys011`은 실제 알파가 있는 시안부터 보완한다.
2. **튜토리얼 도움말 14장**: `ev136`~`ev149`의 본문 전사 → 수치·조건 검수 → 한글 제작 → 페이지별 실행 캡처.

## 재현 명령

```sh
python3 tools/ui_texture_audit.py
python3 tools/ui_catalog.py
PYTHONPATH=tools python3 -m unittest test_ui_texture_codec test_ui_slice
python3 tools/ui_slice.py --output-dir build/ui_slice_next --prepare-only
python3 tools/ui_slice.py --output-dir build/ui_slice_next
```

관련 전체 테스트 49개 통과. 새 ISO는 PCSX2 Software 설정과 프로젝트 BIOS/진행 카드를 사용한다.
초기 카드 전용 도움말 상태는 `build/ui_slice_v2/evidence/help-korean.p2s`이며 UI v2와 해당 초기 카드
사본에서 만든 증거다. 최종 v3와 다른 상태 파일을 섞어 일반적인 호환성을 주장하지 않는다.
