# 승리조건·패배조건 제목의 빨간 효과 정렬

## 문제와 원인

본문의 빨강·주황·검은 효과를 수정한 뒤에도 제목 `bt_tx04`의 빨간 효과는 기존 사용자 배치를 그대로 사용하고 있었다. 앞선 두 수정은 본문만 대상으로 했으므로 제목 오정렬은 남아 있었다.

원본 `bt_sjkn_std.upl`과 `bt_hjkn_std.upl`을 읽으면 기본 제목은 한 글자당 별도 사각형 네 개로 표시한다. 빨간 효과는 문구 전체를 한 사각형에 넣고 가로로 약 2배 확대한다. 승리조건과 패배조건은 빨간 사각형의 시작 위치와 너비가 다르다. 같은 압축이나 이동값을 두 제목에 적용하면 맞지 않는다.

## 수정

기존 사용자 기본 글자 네 조각을 실제 메시 위치에 합쳐 공통 기준 이미지로 만들었다. 그 전체 실루엣을 기준으로 빨간 효과를 생성하고 각 제목의 원래 정점·UV 좌표를 역산했다. 흰 테두리까지 포함한 실루엣에 작은 빨간 번짐을 주며 색은 기존 빨간 팔레트를 사용한다.

공통 작업본은 `outputs/battle_headings_aligned_v1/`다. 제목당 기준·빨간 효과 PSD를 제공한다. 입력은 빨간 효과 PSD 두 장이며 기준 PSD는 정렬 참고용이다. 사용자 원래 제목 PSD는 변경하지 않았다.

변경 범위는 bt_tx04의 다음 두 사각형뿐이다. 우측/하단 좌표는 포함하지 않는다.

- 승리조건 빨강: (136,80)~(216,136)
- 패배조건 빨강: (136,136)~(209,192)

나머지 팔레트 인덱스, 원래 헤더와 팔레트는 바이트 단위로 보존했다. 제목의 기본 글자·주황·검은 효과, 앞서 고친 본문의 세 효과, 모든 기존 번역이 유지된다.

## 결과

ISO: `build/battle_heading_v1/Poison Pink (Japan) - Korean heading alignment v1.iso`

SHA-256: `22b4219433f1e3d3d429c1cc6bc37738ea463163782b53d6e1ec47d1c4ea8c58`

최신 검은 효과 수정 ISO 위에서 3,279바이트만 바꿨다. 전체 ISO 변경 범위·인벤토리 일치, TIM2 왕복, 원본 팔레트/헤더 보존을 검사했다. 호환 패치 34개 주소와 ELF CRC 7502FF83 검사를 통과하고 대응 PCSX2 sidecar도 생성했다.

제목 3개, 본문 6개, 기존 코덱/알파 6개로 총 15개 테스트를 통과했다. 공통 좌표로 환산한 빨간 효과의 목표 실루엣 IoU는 승리 0.669→0.952, 패배 0.708→0.957이다. 이 수치는 알파 128 기준 정적 정렬 지표이며 시간축 전체 프레임의 일치를 뜻하지 않는다.

도구는 `tools/build_heading_alignment.py`, 회귀 검사는 `tools/test_heading_alignment.py`다. 실행 검증 기록은 최종 보고서 `reports/battle_heading_alignment_v1.json`을 따른다.

## 실행 확인

별도 PCSX2 2.6.3 Software, 16:9, 1/2 속도에서 복제 상태저장으로 첫 전투 소개를 재생했다. 승리 제목은 `20260919233742`, 패배 제목은 `20260919233757` 캡처에서 빨간 효과가 기준 글자에 맞게 겹치는 것을 확인했다. 두 제목의 불꽃 구간도 각각 `20260919233733`, `20260919233749`에서 확인했다. 모든 캡처는 `build/battle_heading_v1/snaps/`에 있다. 전체 프레임·모든 전투를 검증한 것은 아니다.

테스트 프로세스를 종료하고 프로젝트 설정을 복원했다. 사용자 원본 PSD 5개와 사용자 슬롯 1은 해시가 동일하다. 최종 PNG 및 원래 팔레트를 보존한 TM2를 `localization/artwork/battle_headings_aligned_v1/`에 채용하고 pipeline의 최신 ISO를 갱신했다.
