기존 사용자 번역에서 검토한 문구를 재사용하고, 시스템 안내는 새로 다듬었다. 길이 초과 문장은 의미를 유지하며 간결하게 고쳤다. 루트 소개는 여러 줄 전체의 뜻이 이어지도록 다시 나눴다. 지도 설명은 원문 줄 폭과 줄 수 안에 맞췄다. 기존에 적용된 범위 내 ELF 문구 126곳은 유지했다.

## 적용 구조와 검사

- 메모리카드 안내에는 여러 문자열이 NUL로 연결되어 있다. 이 영역 128곳은 남은 길이를 공백으로 채워 **원래 줄 끝 NUL 위치를 유지**했다. 단순히 번역 직후 NUL을 넣어서 다음 줄을 빈 문자열로 만들지 않는다.
- 버튼 표시용 `@` 토큰, `%s` 및 `%KB` 관련 표기와 명시적 줄바꿈 수를 검사했다.
- 나머지 문구는 기존 문자열과 확인된 정렬용 빈 공간 안에 저장했다. 문자열 중간을 가리키는 참조가 있으면 적용을 거부한다.
- `Now Loading...`의 참조는 일반 참조 검사에 잡히지 않는 MIPS 호출 지연 슬롯이다. 원래 5개 명령어가 일치하고 중간에 해당 레지스터를 바꾸지 않는 것을 확인한 뒤 문구만 교체했다.
- `나데시코`는 원래 이름 칸을 넘는다. 다른 번역 문구 뒤에 확보된 빈 공간으로 옮기고 구조가 확인된 구출 캐릭터 이름 테이블의 포인터 한 곳(`0x3dced8`)만 수정했다. 원래 이름 주소를 사용하는 정렬된 포인터는 해당 한 곳이며, 가까운 LUI 주소 조합 후보도 없음을 검사했다. 이 이름은 실제 화면에서 추가 검증해야 한다.
- 모든 실행 명령어와 ELF 헤더를 보존했다. 전체 포인터 불변을 주장하지 않으며, 위 이름 포인터가 유일한 예외다.
- 새 한글 11자와 정렬용 빈 글리프 1개를 추가해 3,136 → 3,148글리프로 확장했다. 기존 글리프와 매핑은 보존했다. 갤러리 번호 기호 ①②③은 기존 글리프를 재사용했다.
- SYSTEM 아카이브는 기존 빈 공간만 사용했다. ISO 파일 위치·크기와 아카이브 구성원 위치는 그대로다.
- 전체 ISO 비교: **18,622바이트 변경**, 계획 밖 바이트는 모두 동일.
- DMAP·STATUS 전체가 이전 ISO와 같으므로 기존 RTB 대사·DB와 사용자 이미지 28개도 동일하다.
- 관련 검사 **18개 통과**: 시스템 문구 6개, 기존 ELF 치환 2개, ISO·폰트 10개.

## 잔여 텍스트 검사와 한계

구조화 번역표 128,274행을 검사했다. 미번역 일본어 단어가 남은 행과 번역문에 일본어 단어가 섞인 행은 발견되지 않았다. 원문과 같은 825행은 말줄임표·물음표 등의 기호다. 이는 번역표의 문자 검사이며 전체 번역의 정확성이나 모든 게임 화면의 표시를 보증하지 않는다.

ELF의 내부 파일명·디버그 문구·미사용 인물 슬롯·문자처럼 보이는 이진값은 번역 대상에서 제외했다. 문구로 확인한 이번 범위의 참조 미확인 항목과 길이 오류는 모두 해결했다. 이미지 속 잔여 글씨나 추출되지 않은 문자열까지 전수 한글화 완료로 판정하지 않는다.

사용자 방침에 따라 게임 실행·그림 검수는 이번에도 수행하지 않았다. 메뉴 잘림, 연속 안내의 실제 배치, 이름 재배치는 후속 실행 확인 대상이다. PCSX2 2.6.3의 기존 Metal 충돌을 우회하려면 **Software 렌더러**를 사용한다. 이전 튜토리얼에서 확인한 우회이며 최신 ISO의 첫 전투 통과를 보증하지는 않는다.

## 기록과 재현

- 시스템 번역: `localization/system_messages_ko.json`.
- 문구별 보완·줄 배치: `localization/system_messages_overrides.json`.
- 전체 적용 문구·주소·용량·참조·글꼴·해시: `reports/system_messages_v1.json`.
- 잔여 문자 검사와 검사 수: `reports/system_messages_coverage.json`.
- 빌드 도구: `tools/build_system_messages.py`.
- `--prepare-only`는 적용 계획을 검사한다. 실제 빌드는 이미 완성된 ISO 덮어쓰기를 거부한다.
- 읽기용 번역 목록: `reports/system_messages_translations.md`.

기존 사용자 수정 TSV를 덮어쓰지 않았다. 이번 ELF 추가분은 위 JSON과 적용 보고서가 기준이며, 예전 TSV의 보류 상태를 현재 적용 여부로 해석하지 않는다.
