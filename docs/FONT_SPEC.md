# 원본 폰트 저장 규격과 최소 한글 실험

2026-09-15. 바이너리 및 원본 글리프 복원으로 확인한 규격.
실행 검증 결과는 `reports/font_probe.json`과 런타임 보고서를 별도로 확인한다.

후속 실행: PCSX2 2.6.3에서 원본/실험본을 새로 부팅하여 동일한 게임 대화창의 `テージ → 가나다` 출력을 확인했다.
[최초 실행 검증 보고서](RUNTIME_PROBE.md) 참고. 후속 [한 문장 실험](KOREAN_SENTENCE_PROBE.md)에서는 원본 글리프를 보존한 32자 추가와 ID 2047 출력을 확인했다. 큰 용량과 상태 복원 검증은 별도다.

## 저장 방식

- 논리 글리프: 24×24 픽셀, 픽셀당 2비트, 값 0~3.
- 물리 블록: 연속 ID 두 개를 공유하는 288바이트, 행당 12바이트, 24행.
- 각 바이트: x가 짝수인 픽셀은 낮은 니블, 홀수인 픽셀은 높은 니블.
- 각 니블: 짝수 글리프는 하위 2비트, 홀수 글리프는 상위 2비트.

```python
byte_offset = (glyph_id // 2) * 288 + y * 12 + x // 2
shift = (x % 2) * 4 + (glyph_id % 2) * 2
pixel = (font[byte_offset] >> shift) & 3
```

한 글리프를 고칠 때는 해당 2비트만 바꾼다. 나머지 비트에는 이웃 글리프가 들어 있다.
원본 2,016개 글리프를 모두 decode→encode한 결과 원본 290,304바이트와 정확히 일치했다.
`、。あいうアイウテージ日本語`를 복원한 그림에서 픽셀 방향과 글자 모양을 확인했다.

## 일본어 코드의 테이블 인덱스

실제 ELF `0x001d61e0~0x001d6280`에서 추적한 산식:

```python
linear = (code >> 8) * 189 + (code & 255)
if code <= 0x84fc:
    index = linear - 24445
elif code <= 0x9ffc:
    index = linear - 24823
else:
    index = linear - 36919
```

입력 2바이트의 유효성, index >= 0, index < 테이블 길이, glyph ID 유효성은 별도로 검사한다.
0x7f trail은 유효한 문자로 사용하지 않지만 테이블에서 그 위치를 제거해 188열로 압축하지 않는다.
게임의 모든 입력 경로가 이 루틴을 사용하는지는 계속 확인해야 한다.

## 최초 진단용 변경

| 원래 글자 | 게임 코드 | table index | glyph ID | 표시할 글자 |
| --- | --- | ---: | ---: | --- |
| テ | 8365 | 415 | 189 | 가 |
| ー | 815b | 27 | 9 | 나 |
| ジ | 8357 | 401 | 177 | 다 |

이 세 코드가 포함된 모든 문자열에 전역으로 적용되는 **폰트 진단용 치환**이다.
실제 인명 번역이 아니며, 일본어 장음부호도 `나`로 보이는 것이 이 실험의 의도된 부작용이다.
검증 화면에서는 `テージ`가 `가나다`로 보이는지 확인한다.

글리프는 외부 글꼴 없이 직접 만든 직사각형 획이다. 가독성/서체 품질을 판단하는 배포용 글꼴이 아니다.
일반 폰트 파일 증설이나 새로운 코드 슬롯 추가를 하지 않았고, 대사/테이블/설정/실행 파일은 그대로다.

## 정적 검증 결과

- 전체 글리프 왕복 일치: 2,016개.
- 변경 대상 외 글리프 불변: 2,013개, pair를 공유하는 짝수 ID 포함.
- SYSTEM.HED 및 DAT 크기/정렬 보존.
- 원본 ISO 4,245,454,848바이트와 실험 ISO를 전체 비교: 의도한 폰트 픽셀 342바이트만 변경.
- 모든 ISO 파일 LBA/디렉터리 레코드 보존.
- 원본 ISO SHA-256: `081e5c921fc2b0f517f007dfe053935578174a6880949de961e273426b216103`.
- 실험 ISO SHA-256: `921f3381212f71692b25b47d9a90d09e3d18a24c785d228796f15edc04bb97c9`.


원본 게임 폴더를 출력 경로로 사용할 수 없다.
