# 튜토리얼 도움말 14장 한글화

2026-09-15. `ev136`~`ev149`의 제목·본문·페이지 이동 문구 100영역을 번역했다.
기준 빌드는 [스킬 분류·상태·명령 제목 통합본](UI_REMAINING.md)이다.

## 번역 범위와 검수

| 페이지 | 내용 |
| --- | --- |
| 136–137 | 이동과 공격, 무기 선택 |
| 138–139 | 측면·후면 피해, 장궁·단궁 사거리와 인접 공격 제한 |
| 140–142 | 스킬 횟수·공격력, 종류, 획득 방법 |
| 143–145 | 오버킬, 포획, 포획한 마신의 활용 |
| 146–147 | 마신 장벽, 고트아스의 타격 약점 |
| 148–149 | 재행동 조건, 쌍격 |

원본 TIM2에서 전사한 일본어와 한글, 좌표, 원문 영역 해시, 글자 크기는
[help_pages.json](../localization/help_pages.json)에 고정했다. 이 JSON이 재현 입력이며 임시 스크립트가 필요하지 않다.

- 숫자를 NFKC 정규화한 후 원문·번역의 숫자 목록과 순서를 비교한다.
- 오버킬은 **남은 HP에 오버킬 HP 값을 더한 피해**가 필요하다. 예시 `33+10`과 값 `10`을 유지했다.
- 장비로 얻은 횟수와 유닛 자체 횟수를 구분한다. 원본 화살표·`00:05`·`AT 052`는 그대로다.
- 장벽 예시는 **고트아스에 대한 테이지의 타격 공격**이다. 모든 장벽의 약점을 타격으로 일반화하지 않는다.
- `椿姫の館`는 `춘희의 저택`으로 통일했다. 카탈로그 초안의 `관희`는 원문 오독으로 정정했다.
- 그림 속 게임 화면의 일본어 메뉴·이름·수치, 컨트롤러 그림, `Help`·`ATTACK!` 등의 장식 영문은 남아 있다.
  따라서 도움말 그림에 있는 모든 글자를 번역한 것은 아니다.

## 렌더링·컴파일·ISO 계약

사용자가 선택한 Python/Pillow 폰트 렌더링을 사용한다. 기존 Noto Sans KR 파일 해시를 검증하고
4배 크기로 렌더링한 뒤 축소한다. 실제 글자 경계가 영역 여백을 넘으면 빌드를 거부한다.

제목은 승인 영역 양쪽의 빈 배경 색으로 파란 띠를 재구성한다. 본문은 밝은/어두운 원문 잉크와
외곽선을 마스킹하고 인접 색으로 채운다. **편집 영역 안의 배경 복원은 근사치**이며,
일부 띠·말풍선에는 원본과 다른 색 면이 보인다. 최종 배포 미술로 확정한 것은 아니다.

원본 팔레트의 불투명 색으로 다시 인덱스화한다. 각 파일의 크기·TIM2 헤더·원시 팔레트와
승인 영역 밖 픽셀은 보존한다. ISO는 DMAP 안의 해당 TIM2 14개 범위만 수정한다.
ELF·2,212글리프·이전 RTB/DB/UI·UAD·HED·파일 목록·LBA는 변경하지 않는다.

빌드 후 전체 ISO를 독립적으로 읽어 허용한 바이트 변경만 존재하는지 검사한다.
원본 게임 폴더와 완료된 이전 ISO는 입력으로만 사용한다.

## 재현

```sh
python3 tools/help_pages.py --output-dir build/help_pages_next
# 생성된 14개 *.tm2.png를 확인한 뒤 같은 폴더에 ISO 생성
python3 tools/help_pages.py --output-dir build/help_pages_next --build
PYTHONPATH=tools python3 -m unittest test_help_pages test_ui_texture_codec test_ui_slice
```

완료된 ISO/manifest는 덮어쓰지 않는다. 기존 authored PNG와 새 렌더링이 다르면 새 출력 폴더를 사용한다.
최종 생성 입력 사본은 빌드 폴더의 `review.json`, 개별 렌더링 경계·마스크·팔레트 검사 결과는
`manifest.json`과 [정적 보고서](../reports/help_pages.json)에 저장한다.

수치 변경·미검수·원본 해시 변경·겹침·크기 초과 거부, 렌더 재현성, 인덱스 변경 범위를 테스트한다.
기존 회귀와 합친 관련 테스트는 58개다.

## 실행 검증 원칙

새 ISO를 상태 파일 없이 부팅하고 별도 빈 카드 사본과 별도 상태 폴더를 사용한다.
기존 진행 카드는 실행에 연결하지 않고 전후 해시로 보존 여부를 확인한다.
이미지 전용 패치라 ELF CRC는 기준 빌드와 같을 수 있으므로 ISO SHA-256으로 빌드를 식별한다.
다른 ISO의 상태 파일은 새 도움말의 실행 증거로 사용하지 않는다.

실제 표시한 페이지, 다음·뒤로·닫기 동작, 상태 복원은 실행 보고서에 개별 기록한다.
오프라인 그림 확인과 실제 게임 표시를 구분하며, 확인하지 않은 경로를 통과로 처리하지 않는다.

## 최종 빌드

- ISO: `build/help_pages_v7/Poison Pink (Japan) - tutorial help.iso`
- SHA-256: `a3f2c6c3fe10fe0ce3d15e78838a235a69730f332550f297e1b32d62f5481630`
- 크기: 4,245,454,848바이트. 기준 ISO 대비 **509,340바이트 변경**, 전체 독립 대조 통과.
- 14장·100영역의 팔레트 컴파일 결과를 개별 확인했다. 관련 **58개 테스트 통과**.
- 최종 시안은 v7이며 v1~v6는 미완성 비교 자료다. 앞선 완료 빌드는 보존했다.

## 실제 실행 결과와 보류 범위

[실행 보고서](../reports/help_pages_runtime.json). PCSX2 2.6.3, Software, CRC `C6C842C3`.

- 상태 없는 새 부팅과 별도 빈 카드에서 **ev136~ev140의 5장**을 확인했다.
- 136→137·138→139 다음 쪽, 137→136 뒤로, 137·140 닫기 동작을 확인했다.
- 136 상태 저장 → 137을 닫아 대화창 진입 → 같은 ISO 상태 복원을 1회 확인했다.
- 이전 도움말 135, 한글 대사·메뉴, 화염 스킬 연출과 전투 복귀가 유지됐다.
  적 HP·사용 횟수의 정확한 전후 값은 이번 실행에서 증거로 확보하지 않았다.
- 기존 진행 카드와 이전 시험 카드의 전후 해시가 일치했다. 원본 잠금 검사도 통과했다.

사용자가 **“그림확인 그만하자 그건 나중에해도 될듯”**이라고 요청하여 추가 그림 확인을 중단했다.
**ev141~ev149 실행 표시와 그림 미술 보완은 보류**한다. 전체 14장의 번역·정적 주입은 완료됐다.
원본 DMAP RTB 전체에서 `ev141.tm2`·`ev142.tm2` 직접 파일명 문자열은 찾지 못했다.
이는 호출 불가능하다는 뜻이 아니며, 별도 도움말 목록이나 동적 참조 경로를 추후 확인해야 한다.

### 재개 지점

- 프로젝트 PCSX2 PID 64853을 일시정지했다. 추가 화면 확인은 사용자가 다시 요청할 때 진행한다.
- 검증된 상태: `build/help_pages_v7/evidence/help136.p2s`.
- 마지막 진행 보관: `build/help_pages_v7/evidence/paused-current-unverified.p2s`.
  이 마지막 저장의 복원은 확인하지 않았다. 현재 설정과 카드·상태 폴더도 v7 안에 분리돼 있다.
- 마지막 예약 캡처 `help-overkill-intro.png`는 사용자 중단 요청 후 열어 보지 않았다.
  파일 이름만으로 오버킬 페이지를 실제 검증했다고 판단하면 안 된다.
