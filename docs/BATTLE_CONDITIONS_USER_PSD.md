## 입력과 보완

사용자 작업 PSD 자체는 수정하지 않았다. 입력 사본, 합성 PNG, 게임 크기 PNG는
`localization/artwork/battle_conditions_user_v1/`에 보관했다. 제목은 사용자 `(사본)` PSD를 채용했다.
입력 해시와 레이어별 포함·제외 기록은 `reports/battle_conditions_psd_v1.json` 참조.

1. 레이어 이름을 한글식자 레이어로 제한하지 않았다. 표시된 사용자 레이어를 모두 합성했다.
2. 표시 상태였던 `원본_` 일본어 참고 레이어와 회색 확인 배경은 제외했다. 숨겨진 사용자 대체 레이어는 계속 제외했다.
3. 제목 `bt_tx04`는 원본에서 확인한 14개 UV 영역 안에 식자가 들어가는지 검사하고 영역별로 4배 작업본을 축소했다.
4. `bt_tx05` 기본 글자와 `bt_tx08` 실루엣은 글자 알파가 동일했다. 08을 작업본 기준 왼쪽 4px, 아래 6px 이동하여 05와 맞췄다.
5. 붉은 효과 06과 주황 윤곽 07은 원본 연출의 별도 배치를 유지했다. 모두 같은 아틀라스 좌표로 강제로 옮기지 않았다.
6. PSD의 저장된 글자 픽셀을 사용했다. 폰트를 다시 쓰거나 문구를 바꾸지 않았다. 05·06의 8px 외곽선은 캔버스 전체에서 원형 팽창으로 합성해 레이어 경계 잘림을 피했다. Photoshop 렌더러와 픽셀 단위 동일성을 보장하는 구현은 아니다.

## 변환·검증

- 제목 256×256 / 256색, 문구 4종 각각 256×128 / 16색.
- 원본 TIM2 헤더·팔레트·파일 크기와 ISO 배치 유지.
- 게임 팔레트로 색을 근사 변환하므로 PSD와 완전히 같은 색은 아니다.
- 완전 불투명 입력은 미리보기에서 동률인 팔레트 중 저장 알파가 가장 높은 항목을 사용한다.
- 투명 입력의 출력 투명도, 4비트 인덱스 포장, TIM2 재직렬화, 기본 글자/실루엣 알파 일치를 검사했다.
- 변환 결과를 회색 배경 위에서도 확인했다. 투명 PNG를 알파 없이 보는 뷰어에서는 붉거나 주황색 사각형으로 보일 수 있다.
- 전체 ISO 변경 범위 검증 통과. 게임 실행 검증은 하지 않았다.

## 재현

도구: `tools/build_battle_conditions_psd.py`

프로젝트 로컬 의존성 `build/python_psd`의 psd-tools 1.19.0, Pillow 12.3.0, numpy 2.5.3, scipy 1.18.1을 사용한다.
`--prepare-only`는 ISO를 만들지 않고 합성·변환·정적 검사를 수행한다.
일반 실행은 입력 해시 및 기준 ISO 해시를 검증하고 새 ISO를 만든다. 기존 출력 ISO는 덮어쓰지 않는다.
