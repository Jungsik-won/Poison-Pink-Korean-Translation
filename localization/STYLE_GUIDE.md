# 한국어 번역·검수 규칙

## 원문과 문맥

- target은 한국어 UTF-8 편집 텍스트로 보관한다. 게임 저장 바이트는 별도 인코더가 만든다.
- source, raw_hex, 원본 ID/해시는 수정하지 않는다. 오탐이면 exclude 처리하고 이유를 남긴다.
- 화자·호칭·존대 수준은 실제 장면과 인물 관계를 기준으로 확정한다. 짧은 문자열을 자동으로 이름으로 처리하지 않는다.
- 대사에서는 인물 말투를 보존한다. 메뉴는 짧은 명사형, 설명은 명확한 서술형을 기본으로 한다.
- 원문 의미, 조건, 수치, 사정거리, 속성, 대상 범위를 빠뜨리지 않는다. 임의로 설정을 추가하지 않는다.

## 표기와 용어

- 한글은 NFC 완성형으로 정규화한다. 반각 일본어 아이콘처럼 보이는 문자도 맥락 확인 전 삭제하지 않는다.
- 인명·지명·종족·아이템·스킬·시스템 용어는 glossary.csv에 원문/번역/문맥/승인 상태를 기록한다.
- 인계서의 로마자 표기나 기존 JSON만으로 이름을 확정하지 않는다.
- 동일 용어라도 고유명사/일반명사 문맥이 다르면 별도 항목을 만든다.
- 긴 이름의 약칭은 UI 제한이 확인된 후 full/short 이름을 함께 승인한다.
- 마침표, 말줄임표, 따옴표 등은 매핑표에서 지원하는 문자를 선택하고 프로젝트 전체에서 일관되게 쓴다.

## 제어와 줄바꿈

- `\n`은 JSON 안의 개행 표현이다. 실제 제어 토큰/escape 표기는 파서의 확정 문법을 따른다.
- `@g`, `%d`처럼 보이는 변수, 숫자·아이콘, 리소스 경로는 보호 후보로 검토한다.
- 원문 줄바꿈을 초안에서 우선 보존한다. 최종 줄바꿈은 창별 측정 폭과 행 수로 결정한다.
- 문장을 임의로 여러 리터럴/메시지로 나누지 않는다. 분할이 필요하면 코드 흐름 검토 대상으로 올린다.
- 255바이트는 관측된 리터럴의 저장 한도다. 표시 가능한 글자 수와 다르다.

## 완료 표시

- unreviewed: 후보 역할/원문 경계를 아직 확인하지 않음.
- draft: 번역 초안. target이 있어도 게임에 넣을 수 있다는 의미는 아님.
- reviewed: 원문 경계·역할·문맥·용어 검수 완료, reviewer 기입.
- exclude: 번역 대상 아님. notes에 원인을 기록하고 원문은 보존.
- 화면 검수 완료 여부는 qa_matrix 및 화면 증거로 따로 관리한다.
